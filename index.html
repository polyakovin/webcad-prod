01 / The toolkit

Choose a tool

01 / MODEL

Workspace

↗

Build with boxes, cylinders and spheres, or extrude a rectangular or circular profile. Set dimensions and positions in millimeters and rotate bodies around the vertical axis.

Download an editable JSON project or export the visible bodies as STL.
02 / GENERATE

Gear Generator

↗

Set the tooth count, module or pitch diameter, pressure angle, bore and face width. Preview spur, helical or herringbone gears in 3D and add a hub if needed.

Download the gear as STL or its 2D profile as SVG or DXF.
03 / EXTRUDE

SVG Extruder

↗

Open a filled SVG and set its longest side and thickness in millimeters. Overlapping fills merge, and holes and separate shapes are preserved.

Convert text and strokes to filled paths before importing. Download the extruded model as STL.
STL / MODIFY

Boolean Operations

↗

Open two closed STL meshes that use the same scale. Move or rotate the second model to line up the parts.

Join the meshes, subtract the second from the first or keep only their overlap. Preview the result and export it as STL.
STL / EDIT

Mesh Editor

↗

Open a closed STL. Twist the mesh around an axis or scale each axis separately. Pick a point on the surface to drill a through-hole or add a cylinder.

Smooth a patch or the whole mesh. Use undo and redo to review edits, then export the result as STL.
04 / PRESENT

Model Stand

↗

Open an STL, OBJ or basic 3MF model. Frame it in an orthographic view and adjust rotation speed, shadows and the optional watermark.

Record a turntable or camera flyby with the built-in soundtrack. Download MP4 or WebM, depending on browser support.
2D / INSPECT

DXF Viewer

↗

Open a text-based DXF with lines, arcs, circles or 2D polylines. Check dimensions and toggle layers to isolate the geometry you need.

Export the visible outlines as SVG. When the DXF declares supported units, the SVG keeps its physical scale.
FONT / EXTRUDE

Text Extruder

↗

Type one or more lines and choose Noto Sans or Noto Serif, or load a TTF or OTF font. Set the font size, depth and spacing.

Check the measured dimensions and export the lettering as STL. The extrusion preserves holes inside letters.

Your files stay on your device

Workspace saves your project in this browser. Download a JSON copy to back it up or open it on another device.
